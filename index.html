Bind HomePods to the Enchantment

The Trick: Entity naming determines Siri vocabulary. If the entity is named "main bedroom overhead", Siri responds to "Hey Siri, turn off main bedroom overhead" without any Shortcuts setup. Get the names right first.

Deploy Grimoire to All Towers — Ansible

The Great Synchronisation Ritual
- name: Install Zsh + terminal tools
  apt:
    name: [zsh, git, curl, fzf, bat, ripgrep, btop, tmux]

- name: Summon Oh My Zsh
  shell: |
    [ -d ~/.oh-my-zsh ] || sh -c "$(curl -fsSL https://raw.github.com/ohmyzsh/ohmyzsh/master/tools/install.sh)" "" --unattended

- name: Summon Starship
  shell: command -v starship || curl -sS https://starship.rs/install.sh | sh -s -- -y

- name: Deploy grimoire and star charts
  copy:
    src: "{{ item.src }}"
    dest: "{{ item.dest }}"
  loop:
    - { src: dotfiles/.zshrc, dest: "/home/{{ admin_user }}/.zshrc" }
    - { src: dotfiles/starship.toml, dest: "/home/{{ admin_user }}/.config/starship.toml" }

- name: Set Zsh as default wand
  user: name="{{ admin_user }}" shell=/bin/zsh
